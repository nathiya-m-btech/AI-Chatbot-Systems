# AI Chatbot System 🤖

An advanced AI-powered chatbot system built using Flask and Gemini AI.

## 🚀 Features
- AI Chatbot
- Coding Assistant
- PDF Chatbot
- Image Understanding
- Text Summarizer
- Sentiment Analysis
- Translation System
- Voice Bot

## 🛠️ Technologies Used
- Python
- Flask
- Gemini AI
- HTML/CSS/JavaScript

## ⚙️ Installation

```bash
pip install -r requirements.txt
python app.py
````

## 🔑 API Key Setup

Create `.env` file:

```env
GEMINI_API_KEY=your_api_key
```

## 🌐 Run Project

Open:

```text
http://127.0.0.1:5000
```
